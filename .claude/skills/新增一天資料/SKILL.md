# 新增一天資料

引導把當天的 Excel 來源檔放進正確位置、檢查檔名是否符合 build.py 的分類規則，然後接續「更新網站」流程。

## 資料夾與檔名規則

資料放在 repo 根目錄的 `data/YYYYMMDD/`（例如 `data/20260603/`）。`build.py` 的 `classify()` 依**檔名**分類，務必符合下列樣式：

| 檔名樣式 | 用途 |
| --- | --- |
| `台股放量訊號*.xlsx` | 大盤訊號（今日放量、量能延續、出關股、處置股、勝率回測） |
| `{代號}*日報*.xlsx` | 個股券商買賣超前 20 |
| `{代號}*分析結果*.xlsx` | 個股價量與券商明細 |
| `{代號}*charts*.xlsx` | 個股 6 張內嵌走勢圖 |

`{代號}` 為股票代號，例如 `2344`。新增的個股／日期會自動被偵測，**不需改程式碼**。

## 步驟

1. **問清楚日期與檔案**：確認交易日（YYYYMMDD）以及使用者手上有哪些 Excel 檔、目前放在哪裡。

2. **建立資料夾並放入檔案**
   ```bash
   mkdir -p data/YYYYMMDD
   ```
   把 Excel 檔移／複製進去。

3. **檢查檔名**：逐一比對上表樣式。若有不符（例如缺代號前綴、用了錯字），先回報請使用者確認或協助改名，避免被分類成空資料。

4. **若是新個股**：可在 `stock_names.json`（代號→名稱）補上顯示名稱；沒補也能運作（會用來源檔裡的名稱）。

5. **接續更新**：呼叫「更新網站」skill 完成 build → 煙霧測試 → commit → push → 驗證。

## 注意
- build.py 解析靠 `find_header` 找含關鍵欄位的標題列；若來源檔版面變動，可能**靜默回傳空資料**。產生後務必跑煙霧測試並抽看資料是否正常。
